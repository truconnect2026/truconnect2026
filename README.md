## Robotics

- **Design-to-fabrication pipeline.** My own tool: a concept becomes a mesh, then must pass 8 gates
  (shell, unwrap, swing, stack, clash, join, wire, look) before a print pack is written. Python,
  build123d, STEP/STL, cloud builds on GitHub Actions.
- **Vesper.** A fox-shaped quadruped and the first robot through the full pipeline. v5 passes all
  8 gates in CAD: 13.57 kg, 90 tool-free joints, 0 tight cable runs. Not printed yet.
- **Clickpin.** A tool-free locking joint printed as one TPU part, shared by all my designs, with
  a parametric generator and a finite element check.
- **LW-99.** A NEO-class humanoid in design, planned for two desktop machines and no mould tooling.

Pictures, the version history and the source of every number: **[scrylith.com/robots](https://scrylith.com/robots)**
